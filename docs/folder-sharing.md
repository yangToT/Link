# 文件夹共享：已确认的需求，尚未实现

设备所有者在客户端选择本地文件夹并启用共享。共享提供读写权限，包括列出、读取、新建、修改、重命名和删除文件；不限制用户用途，不授予修改 Windows 安全策略或共享权限的“完全控制”。取消共享和卸载只撤销访问与 Link 创建的资源，原文件始终保留。

其他已连接且获准访问的设备自动在 Windows“此电脑”的网络位置中出现对应文件夹，例如 `DM竞品（设备名称）`；显示名重名时加设备标识。可直接双击访问，也在客户端设备详情中列出共享并提供打开入口。默认面向此专用网络内已连接设备，发布时展示这个范围。

使用 Windows SMB 共享，通过 Link 专用地址传输文件。无需云服务器新增公网 SMB 端口，也不依赖二层桥接；管理服务同步共享清单和授权状态，文件不在管理服务器落盘。鉴权使用专用的非管理员共享身份和受保护凭据，不启用匿名访问或关闭 SMB 安全机制。

共享目录和 NTFS 权限需要同时授予读写。为每个获准设备隔离身份和撤销范围，不把 Windows 登录密码分发给全网。Link 管理员权限只决定能否管理组网实例，不自动授予其他机器任意文件的访问权。

资源管理器入口要在实际登录用户的会话中创建和撤销；当前 UI 以管理员运行，需要补充用户会话侧处理，不能仅在 SYSTEM 后台服务中映射盘符。优先添加网络位置，无需抢占盘符；不保证与所有 Windows 版本截图的导航树显示完全一致。

断开连接或撤销授权时断开对应 SMB 会话，取消共享或卸载时移除本产品创建的网络位置、凭据、共享条目、专用身份与相应 ACL 增量；清理失败留下可恢复状态。源设备离线时访问不可用，不伪装成本地副本或自动云备份。

待实现与实测：共享发布 UI、设备间授权和凭据流转、Windows SMB/NTFS 创建与撤销、登录用户会话的网络位置同步、跨设备读写与断开后访问撤销。
