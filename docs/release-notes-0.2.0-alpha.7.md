# Link 客户端 0.2.0-alpha.7

本次仅发布 Windows 客户端，兼容服务端 0.2.0-alpha.6，无需更新服务端。

- 修复按钮本地颜色覆盖悬停样式；增加按下、键盘焦点、禁用及当前页面选中反馈。
- 异步按钮显示“处理中”和活动进度提示，完成前拦截重复操作。
- 保存设置、连接、启停局域网接入、复制诊断和打开外部窗口均显示结果；失败提示使用独立颜色，失败后恢复操作。
- 安装、修复、卸载继续使用 alpha.6 的独立进度弹窗。

完整解压客户端包并运行新版 Link.exe，通过“功能与组件”更新基础组件。保留现有设备身份，无需重新加入。

原生 WPF 回归验证按下样式生效、状态复位、重复点击拦截及成功/失败后的按钮恢复；界面截图使用合成操作，不代表网络业务验收。
