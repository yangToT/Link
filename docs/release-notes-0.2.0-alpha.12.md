# Link 0.2.0-alpha.12

修复设备身份被服务端拒绝后，客户端仍隐藏“重新加入网络”入口的问题。

- 连接收到 403 后显示设备状态说明和重新加入表单；如果只是被停用，可由管理员恢复后直接连接。
- 已删除设备可使用新的一次性加入码注册为新设备。新注册成功前保留旧本地身份；原有开机、自动连接、网卡与局域网组件偏好继续保留。
- 完全退出仍只断开并停止后台，不删除设备身份或服务端设备记录。

本次仅更新 Windows 客户端，服务端保持 alpha.10。家里设备在服务端已被删除，需要管理员提供新的加入码；更新后点击“连接”，再使用出现的重新加入入口。不要先卸载客户端。

本机编译、自测和界面操作检查通过。家里电脑实际重新加入和完全退出后的恢复仍需现场验证。
