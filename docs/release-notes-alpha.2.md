# Link Windows 客户端 0.1.0-alpha.2

- 添加深绿底色的应用图标，支持窗口、任务栏、快捷方式与系统托盘。
- 最小化和关闭窗口收起到托盘；双击托盘图标恢复窗口。
- 托盘菜单提供打开 Link、打开管理中心、退出界面并保持后台连接。
- 再次启动客户端恢复已有窗口，不再重复打开界面。

本次仅更新 Windows 客户端，与 0.1.0-alpha.1 服务端兼容，服务端无需更新。

验证：真实 Windows 托盘生命周期自测、原有客户端自测通过；已在实际 Windows 设备连接云端并验证私有管理登录。两台 Windows 跨网互连、完整系统重启及实际应用调用仍待验收。
