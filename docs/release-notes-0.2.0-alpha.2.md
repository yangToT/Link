# Link 0.2.0-alpha.2

Windows 客户端新增“功能与组件”页面，可安装、启用、停用、修复和卸载可选局域网接入功能。二层接入仍默认关闭，安装组件不会自动桥接网卡。

- 修正 Bridge 管理认证模式，以及 vpncmd 将 UTF-8 BOM 识别为命令字符的问题；加入非交互运行和安装验证超时。
- 提供 Linux 服务端和 Windows Client/Bridge 组件准备脚本。Windows 使用独立随机密码、DPAPI 和受限本机管理接口。
- 客户端按需下载固定哈希的官方安装包，验证安装包和提取载荷的签名。正常启动界面不再要求提权，系统安装操作通过单独的管理员进程完成。
- 各设备分别报告本机启用意愿与组件状态；未启用或未准备的设备不接收二层凭据，入口停用会撤销依赖它的接入授权。后台控制管道仅授权安装账户与管理员。
- Windows 卸载程序按安装记录清理自有 SeLow 驱动及驱动包；保留预先存在或被其他 SoftEther 服务使用的组件，失败保留恢复数据。
- 引导脚本保留已配置二层端点的私有防火墙规则；准备组件不会自动改变接入模式。

发行包包含 Link 程序及准备脚本，不含 SoftEther 二进制文件；Windows 在用户安装功能时下载官方 Stable 4.44 Build 9807 组件，服务端组件仍需部署时准备。Linux 完整组网部署仍依赖独立网络组件，Windows 服务端 EXE 包含控制服务和内嵌网页。

验证范围见 [验证记录](https://github.com/yangToT/Link/blob/v0.2.0-alpha.2/docs/validation.md)。已验证云端组件接口和一台 Windows 的 Client/Bridge 管理认证；双机 DHCP/桥接、双方代理 TUN 共存、真实业务调用及完整卸载仍未验收。文件夹共享未包含在本版本中。发行程序未代码签名，版本为预发布。
