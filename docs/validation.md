# 0.1.0-alpha.1 验证记录

日期：2026-09-22。

## 通过

- Go 测试及 `go vet`：公网管理隔离、加入码单次使用、底层失败不消耗加入码、令牌散列存储、停用拒绝重连、暂停不自动恢复、会话来源绑定、CSRF、映射端口唯一分配、过期心跳不显示在线。
- Windows 构建与无管理员自测：地址校验、网络分类、IPC 序列化、真实本机 TCP 中转 1 MiB 数据及半关闭响应完整性。
- 正式 Web 前端 Playwright 检查：设备列表、加入码对话框、应用映射、启动参数、375px 布局、无 JavaScript 错误。API 为合成测试数据。
- Windows 客户端实际校验云端 TLS；错误的 CA 指纹被拒绝。内核 Job Object 的子进程退出约束通过自测。
- 外部 UDP 3478 STUN 收到合法绑定响应。
- WPF 离屏布局渲染；未验证实际系统毛玻璃合成。
- Linux 原生组网组件、控制服务和专用管理节点真实启动，无 Docker。
- 外部网络校验实例 CA 后访问 HTTPS：`/health` 为 200；`/`、`/api/state`、`/api/setup`、`/app.js` 为 404。
- 云端通过专用网络地址访问内嵌网页为 200，未授权私有 API 为 401。
- 部署前后原有六项服务的进程号、状态和启动时间完全一致。

## 未验收

- 当前 Windows 会话没有管理员权限，尚未验证驱动安装、后台服务安装、自启、证书安装和卸载恢复。
- 两台真实 Windows 跨网络连接、RDP、原地址资源访问。
- Windows 入口反向转发、实际应用注册与调用。
- 已有数据流的撤销时限、断电/断网恢复、P2P/中继切换与吞吐。
- 重叠网段消歧、回环服务桥接、UDP 映射尚未实现。
- Windows 完整组网服务端安装：EXE 当前仅包含控制面与网页。

GitHub SSH 与 API 身份均已验证，公开仓库为 https://github.com/yangToT/Link。发布结果以 GitHub Releases 的实际资产为准。
