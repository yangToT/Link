# Link 0.2.0-alpha.1

服务端与 Windows 客户端同时更新。请先升级服务端，再升级客户端，保留原实例数据和设备身份。

- 管理中心使用 SSE 接收状态变化，移除每 5 秒全量轮询。
- 客户端通过 SSE 接收配置变更，保留每 15 秒 HTTPS 心跳；支持断线重连、权限撤销及状态乱序保护。
- 提供 Windows 客户端、Windows 控制服务和 Linux 服务端卸载入口及脚本。
- 新增物理网卡识别和可选二层接入的开发预览代码，默认关闭。此版本不包含 SoftEther 组件，未完成跨机桥接和双端 TUN 验收。
- 管理网页使用通用服务地址描述，说明普通成员与管理员的权限区别。

文件夹读写共享仍为待实现需求，不属于本次发布功能。

本地验证：Go 测试/vet、Windows 客户端自测、SSE 接收/重连/撤销、HTTP/2 保活、网页交互与卸载替身测试。已升级一台 Linux 云端和一台 Windows 客户端，验证实际连接、两类 SSE 和私有管理登录；其余服务状态及本机默认路由、DNS、TUN 网卡状态保持一致。详情见 [验证记录](https://github.com/yangToT/Link/blob/v0.2.0-alpha.1/docs/validation.md)；不代表两台 Windows 跨网、真实卸载、应用调用及代理共存已经全部验收。

使用原有端口，无需新增公网安全组规则。Windows 服务端 EXE 包含控制服务与内嵌网页，完整组网部署仍需要独立网络组件，当前完整部署包面向 Linux。所有发行文件未代码签名，属于预发布版本。
