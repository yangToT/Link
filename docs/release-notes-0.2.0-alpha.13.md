# Link 0.2.0-alpha.13

修复 Windows 在 DHCP 取址期间暂时没有虚拟网卡 IPv4 地址时，Link 误将 CIM 查询结果当作致命错误、拆除连接并重新取址的问题。客户端现在保留现有网卡和会话，继续等待地址；地址恢复后照常检查路由、DNS 与默认网关。

本次仅更新 Windows 客户端，服务端保持 alpha.10。家里电脑可在“设置 → 检查更新”升级，不要卸载或重新加入。家里长期稳定性仍需升级后观察。

反向远程桌面不通另有原因：家里电脑是 Windows 11 家庭版，无法作为 Windows 内置 RDP 主机。当前两条 Link 地址已有其他 TCP 端口从本机连通；若需使用 `mstsc` 连接家里电脑，目标系统需支持 RDP 主机。
