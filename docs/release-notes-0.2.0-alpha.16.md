# Link 0.2.0-alpha.16

修复局域网成员的地址反复变化：入口设备的局域网 IP 在同一网络内变化时，不再重建成员网卡；成员新建虚拟网卡时使用由设备身份导出的稳定 MAC。网络短暂异常后如需重建，DHCP 将看到同一 MAC。真正固定局域网 IP 仍需在入口网络的 DHCP 服务器上为该 MAC 配置地址保留。

首次升级会重启 Link 后台并重新创建成员网卡，当前地址可能变化一次。更新后应读取新网卡的 MAC，再设置 DHCP 保留；不要为旧版随机 MAC 配置长期保留。服务端无需升级。

本机真实升级后，SoftEther 新网卡使用预期的稳定 MAC 并取得 DHCP 地址，入口网关连通；未配置 DHCP 地址保留。验证范围以 [验证记录](validation.md) 为准；长时间在线、重启或跨网业务仍待验收。
