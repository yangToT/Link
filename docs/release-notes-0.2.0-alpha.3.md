# Link 0.2.0-alpha.3

Windows 客户端修复版本，兼容 0.2.0-alpha.2 服务端；无需升级或重启服务端。

- 修复中文网卡名称导致局域网接入失败、并循环提示网络清理未完成的问题。Windows PowerShell 5.1 显式以 UTF-8 读取网络请求和恢复记录。
- 清理失败时显示未完成的阶段，保留记录并重试；同步统一卸载组件记录的读取编码。
- 中文无 BOM UTF-8 配置回归、网络归属及恢复替身测试、客户端自测、卸载归属测试通过。两台真实设备间的桥接、DHCP、双向业务和两端代理共存尚未完成验收。

本次仅发布 Windows 客户端安装包。服务端继续使用 0.2.0-alpha.2。
