# Link 0.2.0-alpha.4

- 客户端关闭窗口可选择收起到托盘、仅退出界面、断开并停止后台；托盘新增完全退出。先清理网络再停止 LinkAgent 和自有可选组件，清理失败保留恢复记录。下次启动可复用设备身份连接。
- 管理中心新增删除设备：撤销设备访问、清理关联映射及入口路由，清理失败保留记录供重试。离线记录保留，正常重连不新建设备；同名设备通过标识和最后活动时间区分。
- 修复组件安装日志显示 SUCCESS 后仍误报失败：子 PowerShell 脚本使用异常传播，不再依赖空或残留的 LASTEXITCODE。
- 修复 Windows 入口桥接必须携带组件网卡 ID 的要求；用物理网卡 GUID 计算并对照组件实际列表，拒绝不匹配的网卡。
- 组件页面增加复制诊断和失败阶段，启用校验成功后清除旧错误提示。
- 源码完整构建会自动校验和准备 NetBird/Wintun；首次构建需要 Python 3.9+ 和下载网络，缓存可离线复用。

通过 Go 测试/vet、客户端自测/托盘测试、PowerShell 安装编排回归和合成网页删除交互测试。真实双机 DHCP/桥接、两端代理共存及远端业务调用仍需单独验收。未替用户自动删除任何既有设备。

云端和当前本机已升级，真实停止/重连核验通过：自有服务与网络进程停止、二层日志清理、设备身份保持，默认路由/DNS/TUN 状态一致。入口已配置桥接，但这不等于两台设备的端到端业务验收。
