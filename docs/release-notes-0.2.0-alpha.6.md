# Link 0.2.0-alpha.6

- 完整卸载、安装/修复/卸载局域网组件、基础组件安装增加进度弹窗，显示当前真实阶段；下载和系统操作使用活动进度条，仅完成核验后显示完成。
- 完整卸载识别从解压目录运行的 Link，停止并等待进程退出；只清理已确认的程序文件，保留同目录中的其他文件和下载压缩包。
- 释放服务句柄并检查服务删除结果；网络恢复失败、进程残留、文件占用和缺少完成确认均不得报告成功。失败保留日志，身份清理在程序清理之后执行。
- 客户端和管理中心设备列表增加局域网接入标识，区分未开启、已开启待接入、入口就绪、已取得地址、异常和离线待确认。取得地址不代表业务验收完成。

升级：完整解压后运行新版 Link.exe，在“功能与组件”更新基础组件。卸载旧版残留时运行完整新版包中的 Uninstall.exe；卸载会清除本机身份，再次加入需要新的加入码。

验证：隔离目录使用真实测试进程和文件锁验证退出、清理失败与重试；系统网络/服务命令使用替身。原生进度窗验证运行中刷新、失败显示和完成结果；网页验证状态推送及离线标识。未对用户正在使用的设备执行破坏性卸载验收。
