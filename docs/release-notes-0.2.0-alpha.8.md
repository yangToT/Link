# Link 0.2.0-alpha.8

本次发布 Windows 客户端，服务端继续使用 0.2.0-alpha.6。

- 新增客户端更新检查、下载进度、取消下载、立即/稍后更新、跳过当前版本，以及下载后的立即/稍后重启。
- 更新以 GitHub Releases 完整发布包为准，单独推送代码不会触发；安装保留设备身份和设置，检查失败回退。
- 修复 Windows 局域网接入创建网卡失败（原 NicCreate 退出码 32）：选择 SoftEther 支持且尚未占用的名称，记录网卡 GUID，清理时核对身份。
- 后台服务直接调用官方签名驱动安装器，无需交互辅助进程；不开放特权本地通知端口。
- 复制诊断包含当前接入结果，明确区分历史安装成功与当前连接失败。

alpha.7 及以前须先手动安装此版本。解压完整客户端包，启动 Link.exe，在“功能与组件”中更新基础组件，重新打开安装目录中的 Link。无需卸载、删除设备或重新使用加入码；已有局域网组件可继续使用。

验证：客户端构建与回归检查、真实签名网卡创建及清理、本机安装健康检查失败后的回退与再次升级、私有管理和 SSE 恢复均通过；默认路由、DNS 和 TUN 基线保持一致。家里设备升级后的 DHCP 取址和真实跨网双向访问尚未验收。未来 Release 到客户端完整自动升级链仍待下一版发布后验证。

详见 [客户端更新](client-updates.md)。
