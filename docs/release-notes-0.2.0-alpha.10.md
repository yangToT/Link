# Link 0.2.0-alpha.10

修复局域网成员已获得 DHCP 地址却被网络保护反复断开的问题，并防止后台暂时无响应时误导用户重新注册。

- 仅清除 Link 自建虚拟网卡上的默认路由，保留 DHCP 地址；虚拟网卡沿用本地 DNS，物理网卡与代理配置不修改。
- 专用网络短暂重连时保留已有资源最多 30 秒，超时清理；身份失效、停用或撤销仍执行清理。服务端区分临时重连与授权失效，不在等待期间续发授权。
- 界面读不到后台时保留已知身份状态，注册前再次确认。卸载器增加保留设备身份选项，默认保留；明确清除身份后再次加入仍会成为新设备。
- 复制诊断包含最近一次局域网失败原因和时间，便于定位实际错误。

本次提供 Windows 客户端、Windows 控制服务和 Linux 完整服务端包。alpha.8 及以后可在设置中检查更新；下载后选择立即重启或稍后重启。**不要先卸载，也不要重复输入加入码。**

已用真实 Windows 客户端连接隔离云端 Hub，完成 DHCP 取址、网络保护检查与断开清理。该测试没有接入办公网络，不等于家里与办公网络双向业务验收。详细检查见验证记录。
