# Link 0.2.0-alpha.9

修复成员设备局域网接入停在 `AccountDetailSet`、退出码 38 的问题：使用与固定 SoftEther Stable 4.44/9807 兼容的命令参数。

- 保留账号认证、服务器证书校验和连接前的网络保护；没有更换组件版本。
- TCP 传输限制改用服务端专用 Hub 支持的选项，新部署自动配置；既有部署按 [局域网接入说明](layer2.md) 执行一次维护脚本，无需重启。
- 服务端程序仍为 alpha.6。本次发布 Windows 客户端包。

alpha.8 用户可在“设置 → 检查更新”下载，完成后选择“立即重启”或“稍后重启”。无需卸载组件、删除设备或重新加入网络。alpha.7 及以前须手动安装完整包。

构建、自测、WPF 操作反馈及网络保护脚本回归通过。真实成员与隔离云端 Hub 认证连接成功，清理后默认路由、DNS 和网卡清单保持一致；本机 alpha.8 → alpha.9 客户端更新任务成功，升级后后台连接及私有管理/SSE 检查通过。真实连接与升级测试的范围见 [验证记录](validation.md)；家里电脑 DHCP 取址与双向业务访问仍需实际验证。
