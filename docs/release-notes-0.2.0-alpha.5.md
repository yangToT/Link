# Link 0.2.0-alpha.5

包含 0.2.0-alpha.4 的完整退出、管理员删除设备、组件安装误报修复和 Windows 桥接网卡 ID 修复。

补充修复主动退出与管理员踢下线的区别：主动退出由客户端停止自有网络进程，服务端立即更新离线状态并保留底层节点与路由引用；再次连接复用节点。管理员踢下线、停用和删除仍撤销访问权限。回归测试验证重复退出/重连不删除节点、路由或改变设备身份。

升级后可在关闭窗口或托盘菜单选择“断开并停止后台”；管理中心可显式删除旧设备。家里电脑安装日志已显示 SUCCESS 的情况无需反复卸载重装，更新基础组件后可直接尝试启用局域网接入。

云端其他服务不变；真实两端业务和代理共存仍需单独验收。
